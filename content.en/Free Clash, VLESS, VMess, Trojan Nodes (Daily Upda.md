# Common Import Issues

## Why are there no nodes after importing?

Possible reasons:

* Incorrect subscription URL
* Network cannot reach the subscription server
* Outdated client version
* Nodes are being updated

Solutions:

1. Check the subscription URL
2. Update the client
3. Delete the old subscription and re-add it
4. Try again with a different network

## Clash Verge Rev shows a configuration error?

Common causes:

* Using an old Clash kernel
* Incompatible YAML format
* Expired subscription URL

Suggestions:

* Use the latest Clash Verge Rev
* Use the Mihomo kernel
* Update the subscription again

## Why can’t I connect on iPhone?

Check:

* Whether VPN configuration is allowed
* Whether the proxy is enabled
* Whether a valid node is selected
* Whether other VPN apps are turned off
