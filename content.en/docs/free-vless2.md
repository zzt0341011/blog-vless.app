# Common Import Issues

## Why are there no nodes after import?

Possible reasons:

* Incorrect subscription URL
* Network cannot reach the subscription server
* Outdated client version
* Nodes are currently being updated

Solutions:

1. Double-check the subscription address
2. Update the client
3. Delete the old subscription and re-add it
4. Try a different network

---

## Clash Verge Rev shows a configuration error

Common causes:

* Using an old Clash core
* Incompatible YAML format
* Expired subscription URL

Recommendations:

* Use the latest Clash Verge Rev
* Switch to the Mihomo core
* Re-update the subscription

---

## iPhone cannot connect

Check:

* VPN configuration permission is granted
* Proxy is enabled
* A working node is selected
* Other VPN apps are closed
